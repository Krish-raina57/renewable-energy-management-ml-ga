# Data files

The notebook uses two cleaned CSV files supplied separately by the project author:

- `PV_dataset_clean.csv`
- `Clean_demand_dataset.csv`

The research paper identifies PVGIS as the PV data source and an Irish energy-community dataset as the demand/energy source. Before publishing the raw CSVs in this repository, verify the original dataset download links, attribution requirements, and redistribution licence.

For now, keep the CSVs outside the public repository and update the notebook's file paths locally. Do not commit restricted data or personal/sensitive records.
